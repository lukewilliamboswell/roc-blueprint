= roc-blueprint 0.14.1

Blueprint builds with and embeds Roc `nightly-2026-11-25-d5a4f1e`.
The nightly compatibility workflow retries transient Roc package downloads
and reports exhausted download attempts separately from compatibility failures.
The Spec and lock formats are unchanged.

== Upgrade

Install the Blueprint binary from this release and use its platform in Blueprint.roc.

[source,roc,snippet=unchecked]
----
app [config] { pf: platform "{platform-url}" }
----

Use the release's Roc nightly to compile consumers of the importable core
package at `{core-url}`.
